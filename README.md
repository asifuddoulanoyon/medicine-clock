# ঔষধের ঘড়ি · Medicine Clock

একটি Android অ্যাপ যা ঠিক সময়ে জোরে অ্যালার্ম বাজায় আর মুখে বলে দেয় কয়টি ঔষধ, কোনগুলো, কতটুকু, খাওয়ার আগে না পরে।

**ডাউনলোড:** [Releases](../../releases/latest) পেজ থেকে `MedicineClock.apk` নামিয়ে ইনস্টল করুন।

- নিজের বা পরিবারের যে কারো জন্য (আব্বা, আম্মা…)
- ট্যাবলেট, ক্যাপসুল, সিরাপ, চোখ/কান/নাকের ড্রপ, মলম/পেস্ট, ইনহেলার, ইনসুলিন, ইনজেকশন…
- খাবারের আগে/পরে নির্দিষ্ট মিনিট, নির্দিষ্ট সময়, কয়েক ঘণ্টা পর পর, বা শুধু প্রয়োজন হলে
- অ্যাপ বন্ধ বা ফোন লক থাকলেও অ্যালার্ম বাজে
- ভুল সময়ে সতর্ক করে (যেমন সকালে ঘুমের ঔষধ, গ্যাস্ট্রিকের ঔষধ ছাড়া ব্যথানাশক)

এই অ্যাপ শুধু মনে করিয়ে দেয়, ডাক্তারের বিকল্প নয়।

Every push to `main` builds a new APK with GitHub Actions and publishes it on the Releases page.
